# Bluesky Campus Discovery

A mini prototype for helping new college students find relevant people, feeds, and campus conversations on Bluesky during their first week.

## Why this prototype

Our interviews found that students like Bluesky's calmer, more conversational experience, but often leave when relevant people, topics, and custom feeds are hard to find. This concept improves discovery while keeping users in control of what they follow.

## What the button does

1. Choose one or more interests.
2. Click **Build my campus feed**.
3. The page updates with conversations that match the selected interests and confirms that the feed is ready.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```
